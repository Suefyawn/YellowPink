# UI/UX Audit — local dev, 2026-05-19

Run against `npm run dev` (`localhost:3000`) with stub Supabase (demo mode).
Both desktop (1280×800) and mobile (375×812) viewports.

Severity:
- **P0** — broken (overlap, off-screen, can't read, can't click)
- **P1** — visibly wrong (alignment, spacing, contrast)
- **P2** — polish (could be nicer; not blocking)

## Findings

### P0 — broken

- [ ] **Async-client-component crash** in root layout. `SearchOverlayWrapper` (async server) was imported into `SiteChrome` (`'use client'`). Result: every page suspended on uncached promise + flooded console with errors. **Fixed:** moved data fetch to `app/layout.tsx`, pass `searchTrending` / `searchCategories` as props through SiteChrome to the now-sync SearchOverlay client. Deleted `SearchOverlayWrapper.tsx`.

- [ ] **AddToCartToast fires on page-load hydration.** Cart persists to localStorage, so `cartCount` goes from `0 → N` between first render and hydration; the effect sees `cartCount > prev` and toasts something the user did on a prior visit. Reproduces 100% with a saved cart.

### P1 — visibly wrong

- [ ] **Three-banner stack** at the top of the page in demo mode (DemoBanner yellow → AnnouncementBar dark → PromoBanner pink hero strip). Real prod will show 1–2 of these, but visually the demo banner clones AnnouncementBar's bg/spacing so it reads as duplication. DemoBanner should be visually distinct or render below the chrome.
